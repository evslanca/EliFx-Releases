# EliFx Portable (Windows 10 / 11 x64)

Download oficial da versao portatil do **EliFx**.

## Download
- Acesse a aba **[Releases](https://github.com/evslanca/EliFx-Releases/releases/latest)** e baixe **EliFx-Portable-v1.0.18-win64.zip** (pacote completo) ou **EliFx.exe**.

## Como usar
1. Extraia o arquivo EliFx-Portable-v1.0.18-win64.zip em qualquer pasta ou pendrive.
2. Execute **EliFx.exe** (nao precisa instalar Visual C++ Redistributable).
3. Se o PC ainda nao tiver o driver virtual de audio instalado, execute **Instalar-Driver-Audio.bat** como Administrador uma unica vez.
4. Suas configuracoes e presets ficam salvos na pasta **Data\** dentro da pasta do programa.
